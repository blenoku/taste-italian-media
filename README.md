# Taste Italian - media archive

Public folder with the social media graphics and videos for Taste Italian, a pizza food trailer in Bedford, UK.
Instagram: @taste.italian.bedford

Images are JPEG files and videos are MP4 files, organised by month (`2026-10/`).

## Marketing mod

`/marketing-settimana` runs the weekly workflow: competitor research, weekly plan, editing, quality checks.
Finished content lands in `finiti/<week>/` and is published only after the owner confirms.
Settings live in `marketing/config.md`.
